# Phishing Analysis

Разбор подозрительных писем: заголовки, отправитель, вложения, IOC и вердикт.

## Кейсы

| Кейс | Сценарий | Verdict |
|------|----------|---------|
| [case-001](case-001.md) | Письмо «Бесплатный купон на кофе» с вложением `.zip` | True Positive |

## Что отрабатываю

- Анализ sender, reply-to и заголовков письма
- Проверка вложений и ссылок
- Сбор IOC: IP, домены, URL, хеши
- Проверка репутации в VirusTotal
- Verdict и краткая рекомендация по реакции

## В планах

- Разбор SPF, DKIM и DMARC
- Анализ email headers полностью
- Работа с песочницей для вложений
