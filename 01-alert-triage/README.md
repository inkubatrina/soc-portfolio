# Alert Triage

Разбор входящих security alerts: что произошло, какие IOC, насколько критично, какой verdict и нужна ли эскалация.

## Кейсы

| Кейс | Сценарий | Verdict |
|------|----------|---------|
| [case-001](case-001.md) | SOC325 — попытка несанкционированного доступа к облачному региону | True Positive |

## Что отрабатываю

- Чтение данных алерта: правило, источник, назначение, действие устройства
- Сбор IOC и проверка репутации (VirusTotal, AbuseIPDB)
- Определение масштаба и необходимости изоляции
- Сопоставление с MITRE ATT&CK
- Verdict и краткая заметка аналитика
