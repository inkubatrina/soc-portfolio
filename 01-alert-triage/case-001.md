# Case 001 — Попытка несанкционированного доступа к облачному региону (SOC325)

## Метаданные

| Поле | Значение |
|------|----------|
| Платформа | LetsDefend |
| Правило | SOC325 — обнаружена попытка несанкционированного доступа к облачному региону |
| Тип оповещения | Web attack |
| Сложность | Easy |
| Время события | 2024-09-24T08:21:15+03:00 |
| Пользователь | test@letsdefend.io |
| Источник | 134.209.145.73 |
| Назначение | 52.15.206.21 |
| Запрос | `POST /accounts/login HTTP/1.1` → `403` |
| Действие устройства | Заблокировано |
| ОС цели | Linux, Ubuntu 20.04.02 |

## Краткое описание

За короткий промежуток времени зафиксировано множество попыток входа в аккаунт `test@letsdefend.io` с одного IP-адреса из неавторизованного (неиспользуемого) облачного региона. Запросы к `POST /accounts/login` завершались кодом `403` и блокировались на уровне прокси/файрвола.

## IOC

| Тип | Значение | Комментарий |
|-----|----------|-------------|
| IPv4 (источник) | `134.209.145.73` | Атакующий IP |
| IPv4 (назначение) | `52.15.206.21` | Целевой хост |
| URL | `POST /accounts/login` | Точка атаки |
| Аккаунт | `test@letsdefend.io` | Цель перебора |

## Расследование

### 1. Первичная проверка

Множество попыток входа за короткое время с одного адреса указывало на brute-force. Возможен также сценарий с использованием прокси для распределения трафика.

### 2. Проверка репутации IOC

IP `134.209.145.73` найден в VirusTotal и AbuseIPDB в категориях: malware, SSH-атаки, phishing, brute-force. Адрес геолоцируется в Индии. Репутация подтверждает вредоносную активность.

### 3. Масштаб

При поиске IP атакующего в логах в качестве цели обнаружен только `52.15.206.21`. Других затронутых систем нет.

### 4. Проверка на хосте (Linux)

Для подтверждения/опровержения компрометации проверяются:

- `/var/log/syslog`, `/var/log/auth.log` — события аутентификации;
- `/var/log/audit/audit.log` — доступ к файлам, системные вызовы, изменения конфигурации.

### 5. MITRE ATT&CK

| Техника | ID | Тактика |
|---------|----|---------|
| Compromise Accounts | T1586 | Resource Development |
| Valid Accounts | T1078 | Initial Access / Persistence / Privilege Escalation / Defense Evasion |
| External Remote Services | T1133 | Initial Access / Persistence |
| Unused/Unsupported Cloud Regions | T1535 | Defense Evasion |

Метод уклонения от защиты в этом кейсе — использование **неиспользуемых/неподдерживаемых облачных регионов** (T1535), а не просто «обход сетевых барьеров».

## Verdict

**True Positive.** Зафиксирована вредоносная brute-force активность с IP с плохой репутацией.

При этом:
- все запросы блокировались файрволом/прокси (`403`);
- признаков успешного входа нет;
- затронут только один хост.

Поэтому **изоляция устройства не требуется**, а масштаб ограничен одной системой. Достаточно мониторинга и блокировки IP.

## Выводы

- Verdict «вредоносная активность» не всегда означает «изолировать хост»: важно проверять, был ли успешный вход и затронуты ли другие системы.
- Репутация IP — сильный сигнал, но не замена анализу логов.
- В следующий раз быстрее определять метод уклонения через MITRE ATT&CK (T1535), а не общими формулировками.
